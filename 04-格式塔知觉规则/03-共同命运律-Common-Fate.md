# 03 ｜ 共同命运律 Law of Common Fate

> **概念定义（课程口径）**：运动方式相近的元素容易被看成一组。
> **信息图形设计示例（课程口径）**：动态迁移图用同向移动的点表达同一流向。
> **一句话**：一起动、朝一个方向动的，读成一组。
> **证据**：原始文献（Wertheimer 1923）｜C 节数值均为经验值（待验证）
> **导航**：14 条之 3 ｜ [总览](00-总览与索引.md) ｜ 上一篇 [相似律](02-相似律-Similarity.md) ｜ 下一篇 [良好连续律](04-良好连续律-Good-Continuation.md)

## A 概念定义

### A.1 课程定义（逐字保留）

> 运动方式相近的元素容易被看成一组。

关键词是**运动方式**——方向、速度、加速度、节奏。"相近"不等于"完全相同"：同向但速度略有差异的点，仍会被读成同一群；方向相反的，即使挨得很近也会被拆开。

### A.2 原始文献表述

Wertheimer 1923 的因子之一：**gemeinsames Schicksal（共同命运）**——经历相同变化的元素倾向被组织为同一单元。原文的"命运"比"运动"宽，凡是"一起被改变"都算；后来的实验传统把它收窄为**同时同向的运动**（本层按课程口径处理为运动）。

### A.3 可操作版（判定式）

在一段可观察的时间内，若一组元素**沿同一方向、以相近速度**位移（或同时出现、同时消失），它们被读成一组；同一时刻朝不同方向运动的元素被读成不同组。

判定式：`方向差 ≤ 30°` 且 `速度比 ∈ [0.7, 1.4]` 时，可期望被读成一群。

### A.4 边界：与本层另两条"动态"规则的分工

这三条最容易混，必须分清：

| 规则 | 变化的是什么 | 判定依据 |
|---|---|---|
| **03 共同命运**（本条） | **位置**（运动／出现／消失） | 方向与速度 |
| [08 广义共同命运](08-广义共同命运-Generalized-Common-Fate.md) | **属性**（明度、色相、极性）沿同一方向变 | 变化方向一致，但不动 |
| [09 同步性](09-同步性-Synchrony.md) | **时间**（同一时刻发生变化） | 只要同时，方向可以相反 |

另有一条边界：共同命运**不表达"同类"**。同向运动只说明"同一群"，若这群点还同色，读者会同时读出"同类且同群"——两个判断叠加，容易过度解读。

## B 知觉机制

运动是**强线索**，因为它在时间维度上提供了"共同原因"的证据：一起动，最省事的解释是"被同一个东西推动"。这也是为什么动画里的分组比静态图更"硬"——静态图只能靠暗示（箭头、轨迹、重影），动态图直接给出证据。

## C 编码手段

| 场景 | 做法 | 参数（经验值，待验证） |
|---|---|---|
| 进入／退场 | 同一组元素同时或微错时进入；不同组错开 | 组内 stagger ≤ 50 ms；组间 ≥ 200 ms |
| 位移（迁移图） | 同流向着同向、同速；不同流向用不同色相辅助 | 方向差 ≤ 30°；时长 400–800 ms |
| 高亮传递 | 一组元素依次点亮（"波浪"），组内节奏一致 | 单点 120–200 ms，间隔 40–60 ms |
| 缓动 | 同一组用同一 easing；不同组可用不同 easing 强化区分 | `ease-out` 为主，避免 bounce |
| 静态替代 | 无法动时用箭头、轨迹线、重影（onion skin）暗示方向 | 箭头间距一致，指向差 ≤ 30° |
| 可及性 | 尊重 `prefers-reduced-motion`；提供无动画版本 | 关闭动画后分组须仍成立 |

**关键**：动画的**时长**也是编码。0.1 s 的闪现读成"同时"，1 s 的位移读成"移动"，3 s 的渐变读成"演化"——同一组元素换个时长，语义就变了。

## D 信息图形设计示例与案例

### D.1 课程示例拆解：迁移图的同向点流

> 动态迁移图用同向移动的点表达同一流向。

这条示例同时用了**两条线索的叠加**，这是它稳的原因：

1. **共同命运（主）**：同一流向的点同向、同速位移——这是分组的主证据；
2. **相似（辅）**：同一流向的点同色——这是冗余编码。

拆开看三个动作：① 起点按区域撒点；② 每个点沿一条贝塞尔路径朝终点移动，同流向共用一条路径模板；③ 不同流向错时启动（≥ 200 ms），避免读者把两股流看成一片。

**冗余是有意的**：一旦用户关闭动画（可及性要求），颜色仍在承担分组；只剩动画而没有颜色，关闭动画后分组就消失了。

### D.2 库内正例（静态替代）

**正例 1｜[CASE-0011 城市流程路线](../02-信息图形类型案例/05-流程图型-Process/案例/CASE-0011-城市流程路线/分析.md)**
可见事实：路径由箭头串起，同一路径上箭头朝向一致。本库判读：这是共同命运的**静态替代**——无法播放动画时，用"箭头朝向一致"暗示"同向运动"。若同一路径上箭头方向打架，读者会立刻怀疑那里有分叉。

> **诚实标注**：本库 16 条 CASE 均为课件静态图，共同命运**没有真正的动态正例**。以上是静态替代证据，非本规则的直接验证；动态正例待补（见 [99 附录 待办](99-证据分级与待办.md)）。

### D.3 反例：全体同动 = 没有分组

一段开场动画里，标题、图例、坐标轴、数据点全部以同一时长、同一 easing 淡入。结果读者读不出任何分组——因为**所有元素的"命运"相同**，线索饱和，等于零信息。错在把"动效"当成装饰统一施加，而没有用它**区分**组。修法：给数据点单独的运动方式（如从 0 生长），其余元素静置或极短淡入。

第二个常见反例：两条流向的迁移图**同时**启动、速度相近，只是方向差 150°。读者会看到"一团点同时乱飞"，分组失败——方向差超过 90° 时，必须靠颜色或错时补救。

## E 设计实践经验

- **动效的第一职责是分组，第二才是趣味。** 每个动画都该回答"它在区分哪两组"。
- **不要给所有元素同一种入场。** 统一入场是把共同命运用在"整页"上，只对"整页是一个组"成立。
- **时长即语义。** 想表达"同时发生"就别用 800 ms 的错时；想表达"相继"就别用 0 延迟。
- **静态媒介里，共同命运必须换成别的线索。** 印刷图没有运动，只能用箭头／轨迹／序列帧；此时应把分组责任交给相似或元素连接。
- **线索冲突**：一组元素同向运动，但其中两个落在同一个浅色底板内（共同区域）——**底板通常赢**，读者把那两个读成独立的一组。此时要么拆底板，要么让这两个点的运动方向也分开，制造一致的双线索。

## F 自检清单

- [ ] 每个动画是否对应一个明确的分组判断？
- [ ] 同组元素的方向差是否 ≤ 30°、速度差是否 ≤ 1.4 倍？
- [ ] 不同组的启动时间是否错开 ≥ 200 ms？
- [ ] 关闭动画后，分组是否仍靠静态线索成立？
- [ ] 是否存在"所有元素同一种入场"的整页动效？
- [ ] 运动线索与共同区域冲突时，哪一条更强？是否实测？
