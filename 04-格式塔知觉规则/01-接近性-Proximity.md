# 规则 1 ｜ 接近性 Proximity

> **一句话**：靠得近的，读成一组。
> **证据等级**：原始文献（Wertheimer 1923）｜C 节参数为经验值
> **位置**：本层 11 条主规则之 1 ｜ 总览：[00-总览与索引](00-总览与索引.md)
> **上一篇**：[00 总览与索引](00-总览与索引.md) ｜ **下一篇**：[相似性](02-相似性-Similarity.md)

## A 定义

Wertheimer 1923 列出的第一个分组因子。原始表述大致是：在其余条件相同时，空间或时间上彼此接近的元素倾向于被组织为同一单元。

**可操作版**：当两组元素之间的间距明显大于组内间距时，读者会按"近邻"切块——切块结果与元素的形状、颜色无关。

**边界**：接近只表达"属于同一块"，**不表达"同类"**。同类是相似（[规则 2](02-相似性-Similarity.md)）的事。

## B 知觉机制

知觉系统倾向于用**最短连接**解释元素间关系：把距离近的元素连起来，总描述长度更短（这是"简洁律"的一个特例，见[规则 6](06-良好图形-Pragnanz.md)）。所以接近之所以有效，是因为它让"分组"成为一种**省力的解释**。

## C 编码手段

| 场景 | 做法 | 参数（经验值，待验证） |
|---|---|---|
| 通用分组 | 组间留白 ≥ 2× 组内间距；要"读得出是两组"，建议 3× | 组间 : 组内 ≥ 2 : 1 |
| 表格 | 行内列间距 < 行间距；分组标题上方留白 ≥ 2× 行距 | 分组标题上边距 ≥ 2 倍行距 |
| 标签贴靠 | 标签与所属元素的间距 ≤ 到最近邻元素的 1/3 | ≤ 1/3 |
| 图例 | 图例项之间 ≥ 2×（符号与文字之间的间距） | ≥ 2× |
| 中文正文 | 行距 ≥ 1.5× 字号；段距 ≥ 1.5× 行距 | 行距 1.5–1.8 倍 |
| 时间轴 | 节点间距必须与刻度声明一致（等距／等比），否则接近会伪造"密度" | 见 [时间轴文档](../02-信息图形类型案例/03-时间轴型信息图形-Timeline.md) |

**关键**：间距比是**相对量**。整图缩小 50% 后比例不变，但绝对距离变了——**近距离元素在缩略图上会粘成一片**。所以移动端或缩略图预览必须单独检查一次。

## D 案例

**正例 1｜[CASE-0008 人物文字列表](../02-信息图形类型案例/案例记录/CASE-0008-人物文字列表.md)**（p.23 右，披头士海报）
可见事实：人物照片周围组织标题、图表、文字条目和底部列表。本库判读：海报没有大量用边框，四类内容靠**间距层级**分开——照片与紧随的姓名间距最小，条目之间次之，区块之间最大。这是"只用一条规则"的正面样本：删掉所有颜色，分组依然成立。

**正例 2｜[CASE-0004 绘画编目](../02-信息图形类型案例/案例记录/CASE-0004-绘画编目.md)**（p.11）
可见事实：绘画作品图像与点位图、说明文字并置。本库判读：作品图与其说明文字的距离必须显著小于到下一件作品的距离，否则说明会"贴错"到邻件——编目类图形里，接近是**唯一不能出错**的分组信号。

**反例｜文字块的行距塌缩（通用型，非具体案例）**
当行距降到 1.2× 字号以下，且段间距与行距相同（0 增量）时，整段文字会被读成**一个灰块**，读者只能逐字扫描，无法按段落取信息。错在**没有建立"组内 vs 组间"的差异**——等于放弃了分组信号。信息图里"一段说明文字挤成方块"就是这个症状。

## E 设计实践经验

- **接近是"默认信号"，不是"强信号"。** 它随时被共同区域（[规则 8](08-共同区域-Common-Region.md)）和连通性（[规则 9](09-连通性-Uniform-Connectedness.md)）压过。要表达"归属"，优先加框或连线；只靠间距，读者在复杂版面上会读错。
- **不要用间距表达层级。** "A 是 B 的上一级"加间距，读者读到的是"这两块没关系"。层级用共同区域（框套框）或连通性（缩进＋分支线）。
- **间距比在两种情况下失效**：① 元素本身尺寸差异极大（大元素周围天然有大留白）；② 版面上已有多套网格（栏网格 + 卡片网格），读者不知道按哪套切。
- **时间／类别轴上的"等距"是谎言。** 节点排布等距但时间不等时距，接近会伪造出"密度均匀"的印象；必须标断轴或改成等比（[时间轴文档](../02-信息图形类型案例/03-时间轴型信息图形-Timeline.md) 断轴规范）。

## F 自检清单

- [ ] 组间间距是否 ≥ 2× 组内间距？能否指出具体是哪两组？
- [ ] 把图缩小到 50%，分组是否还成立？
- [ ] 有没有"标签离两个元素都差不多近"的地方？
- [ ] 版面是否存在两套以上互相矛盾的网格？
- [ ] 时间／序数轴上的间距，是否与刻度声明一致？
- [ ] 是否在用间距表达"层级"（应该改用框或连线）？
