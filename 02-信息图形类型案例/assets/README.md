# 图版目录（assets）

本目录存放全部案例图版。**01 层文档不嵌图，所有图片只在这里。**

## 命名规则

```
<类型码小写>-<三位序号>.<扩展名>

m-001.jpg    ← 混合型（Mixed Charts）
l-001.jpg    ← 文字型／列表型（List / Informational）
t-001.jpg    ← 时间轴型（Timeline）
```

系列图加后缀：`t-014-a.jpg`、`t-014-b.jpg`

## 技术要求

- 长边 ≥ 1600px
- JPEG 质量 ≥ 85（需可放大看节点与注记细节）
- 文件名全小写、无空格、不含中文

## 关联规则

- 案例编号（`CASE-M-001`）与文件名（`m-001.jpg`）**必须一一对应**
- 登记表、解析正文、01 层回链三处引用同一编号
- 详细规范见 [README · 案例登记规范](../../README.md#四案例登记规范)
