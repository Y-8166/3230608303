## 本层怎么排

```
02-信息图形类型案例/
├─ README.md                  ← 本文件：板块入口与导航
├─ 00-类型总览.md              ← 全层总目录（00 是「层级索引」，不是第 0 个类型）
├─ <01…17>-<类型名>/          ← 17 个类型文件夹，这里的编号才是类型序号
│  ├─ 00-标签说明.md           ← 该类型的定义 / 规则表 / 案例登记表
│  └─ 案例/
│     └─ CASE-xxxx-简要名/    ← 一案例一目录
└─ <全层文档 7 份>            ← 不带编号，作用于整个 02 层，不属于任何单一类型
```

**带编号的是类型，不带编号的是全层文档**——两者不是同一套序号，不要按数字顺序读。

## 一案例一目录

每个 `CASE-xxxx-简要名/` 固定包含：

| 文件 | 是否必有 |
|---|---|
| `README.md`（一屏卡片）、`分析.md`（A–E 正文）、`原图.webp`、`原图来源.md` | ✅ 一律必有 |
| `数据字典.md` | ✅ 任何 `dataset_status` 都必有（含 `none`） |
| `基础数据集.csv` | 仅 `complete` / `partial` 必有 |
| `辅助指标.csv` | 可选，按图的可复算部分决定 |

图片**只能**放在 `<类型>/案例/CASE-xxxx-名/` 内；本层其它位置、`01-` 层、`03-` 层一律禁图。
