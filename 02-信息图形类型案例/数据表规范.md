# 数据表规范（V3 本库适配版）

> **一句话**：每个案例必须回答一个问题——**这张图的数据在哪、能复算到什么程度、哪些格子是空的**。答不出，就不算分析完成。

**位置**：02 层通用规范 ｜ 接口：[案例分析模板](案例分析模板.md) ｜ 总表：[案例索引](案例索引.md) ｜ 数据位置：各案例目录内（见 §3）

## 1. 为什么本库需要这张表

课件缩略图能看出"用了条形、饼图、人形图标"，却看不出"条形到底对应多少"。此前 16 条案例记录的 B 节都写着"数值无法从缩图确证，不进行虚构计算"——**这句话是对的，但它只完成了防守，没有完成记录**。规范要补的是后半句：把"确证了什么、缺了什么"写进可核查的表格，而不是写在句子里。

三条理由：

1. **可复算**：A 节说"最小数据单位是都市圈"，B 节说"按营收降序"，两句话之间缺一张 15 行的表。有了表，读者能自己验算排名是否成立。
2. **防臆造**：没有表时，"看起来像"会被写成"是"。有表时，每个值必须挂一个来源等级，猜的值无处安放。
3. **可增量**：图版是课件缩图，日后拿到高清原作或官方数据，只需改表中被标为"缺失"的行，不必重写整篇分析。

## 2. 三档数据状态（本库适配的核心）

V3 原文要求"每案必含 `基础数据集.csv` 与 `数据字典.md`"。本库 16 案中 14 案是**纯示意图或纯定性图**，强制执行会产出 14 个只有表头的空 CSV。故改为按状态分档：

| `dataset_status` | 含义 | 必含文件 | 本库现状 |
|---|---|---|---|
| `complete` | 图面观测可全部转录，或已由官方开放数据补齐，并能复算图上关键结论 | `基础数据集.csv` + `数据字典.md`（+ 有图注指标时 `辅助指标.csv`） | 0 例（待补） |
| `partial` | 只能转录一部分；其余格留空并标 `缺失`，字典列出不可推断清单 | 同上 | 5 例：[CASE-0003](07-地标型-Location/案例/CASE-0003-美国疫情地图/数据字典.md)、[CASE-0007](01-混合型-Mixed-Charts/案例/CASE-0007-多主题混合统计/数据字典.md)、[CASE-0009](03-时间轴型-Timeline/案例/CASE-0009-包豪斯时间轴/数据字典.md)、[CASE-0012](06-比较型-Comparison/案例/CASE-0012-体育人物比较/数据字典.md)、[CASE-0014](08-图片式-Photo-graphic/案例/CASE-0014-摄影嵌入图表/数据字典.md) |
| `none` | 图面无可转录数值（纯示意、纯定性、纯版式） | 仅 `数据字典.md`，须写明"为何无值"与"禁止推断清单" | 11 例（[CASE-0001](03-时间轴型-Timeline/案例/CASE-0001-编年曲线/数据字典.md)、[0002](09-层级表现型-Hierarchical/案例/CASE-0002-进化层级图/数据字典.md)、[0004](01-混合型-Mixed-Charts/案例/CASE-0004-绘画编目/数据字典.md)、[0005](02-文字型列表型-Informational-List/案例/CASE-0005-电路符号图鉴/数据字典.md)、[0006](07-地标型-Location/案例/CASE-0006-城市空间规划图/数据字典.md)、[0008](02-文字型列表型-Informational-List/案例/CASE-0008-人物文字列表/数据字典.md)、[0010](04-示意图型-How-to/案例/CASE-0010-分层三明治/数据字典.md)、[0011](05-流程图型-Process/案例/CASE-0011-城市流程路线/数据字典.md)、[0013](07-地标型-Location/案例/CASE-0013-轨道交通网络/数据字典.md)、[0015](15-编年编目复合型-Hybrid/案例/CASE-0015-宇宙旅程混合图/数据字典.md)、[0016](16-三维型-3D/案例/CASE-0016-轴测分层生态图/数据字典.md)） |

> **`none` 不是免做**。它要求回答"这张图凭什么没有数"——是本来就不承载数值（如符号图鉴），还是缩图分辨率不足（如地图），两者含义完全不同，必须区分。

## 3. 文件与命名

**一案例一目录**，数据表与图版、分析同处一室：

```
02-信息图形类型案例/07-地标型-Location/案例/CASE-0007-多主题混合统计/
├─ README.md          ← 案例卡片（一屏看全）
├─ 分析.md            ← 分析正文（A–E）
├─ 原图.webp          ← 图版
├─ 原图来源.md        ← 出处、页码、权利状态
├─ 基础数据集.csv     ← 观测数据
├─ 辅助指标.csv       ← 图注指标、图例刻度、画布事实
└─ 数据字典.md        ← 字段、粒度、来源、缺口
```

- **文件名固定**：`基础数据集.csv` / `辅助指标.csv` / `数据字典.md`，不再带 `CASE-xxxx-` 前缀——目录名已经承担了编号。
- **编码**：CSV 一律 **UTF-8 with BOM**，Excel 双击直开中文不乱码；换行 `LF`。
- **同目录**：拷走一个案例目录，数据表跟着走，不会只剩分析没有表。

## 4. 六条硬规则

1. **一行一个最小观测，一列一个属性，一格一个值**。"北京/上海"写在一个单元格是违规；"Fayetteville–Springdale–Rogers–Bentonville" 是一个法定都市圈名称，属合法复合实体，不拆。
2. **单位不混进数值格**。写 `1775.0` + 字段名 `revenue_usd_billion`，不写 `$1775.0 billion`；或数值格 `1775.0`、另设 `unit` 列。
3. **百分比用 0–100 的纯数字**，字段名带 `_pct`，不带 `%` 字符；分母另设 `denominator` 列，不塞进备注。
4. **每个值可溯源**。无来源的值不许进表；拿不准的值进表但必须降级标记（见 §6）。
5. **不臆造**：企业源表、经纬度、分类键、地图投影、作者制作过程、精确色值——凡是图面推不出的，一律留空并写入字典"不可推断清单"。
6. **可复算**：字典里写出至少一条复算式（如"`rank` 按 `revenue_usd_billion` 降序生成，15 行无并列"），供后来者验算。

## 5. 字段命名约定

| 后缀／前缀 | 用于 | 示例 |
|---|---|---|
| `*_id` | 主键、外键 | `metric_id`、`source_stage_id` |
| `*_en` / `*_zh` | 需双语对照的文本 | `metro_area_en`、`metric_label_zh` |
| `*_pct` | 百分比（0–100） | `satisfaction_pct` |
| `*_count` | 计数 | `employee_count` |
| `*_year` | 四位年份 | `panel_year` |
| `*_usd_billion` 等 | 已带量纲的数值 | `revenue_usd_billion` |
| `unit` | 无法入字段名的量纲 | 值 `therms`、`kWh` |
| `is_*` | 布尔 | `is_estimate` |
| `*_status` | 缺失原因枚举 | `value_status` |

**缺失写法**：数值格留空，由 `value_status` 说明原因（`not_readable` / `not_reported` / `not_applicable`）。**禁止**用 `N/A`、`-`、`0`、`?` 冒充缺失——`0` 是真实观测值，与"读不出"性质相反。

## 6. 来源五级与置信度三级

本库有两套五级，**语义不同，不可混用**：

- **结论证据分级**（写在分析正文，见 [04/99 证据分级](../05-格式塔知觉规则/99-证据分级与待办.md)）：原始文献 / 现代增补 / 教科书转述 / 本库判读 / 经验值。
- **数值来源分级**（写在 CSV 的 `evidence_level` 列）：下表。

| `evidence_level` | 含义 | 举例 |
|---|---|---|
| `图面转录` | 图上明写，逐字照抄 | 图例刻度 `68,775` |
| `图面可辨` | 形可辨但字迹模糊，需标 `confidence` | 缩图上 `97%` 与 `99%` 需逐条核对 |
| `图面计算` | 由已转录字段算出，字典须给公式 | 合计、占比、排名 |
| `官方补充` | 图外权威来源补齐，须记 URL 与统计期 | 官方年报补齐的营收 |
| `缺失` | 图面读不出，且无外部来源可补 | 县级分区逐县病例数 |

`confidence` 只对 `图面可辨` 生效：`high`（可复核）/ `mid`（形似，需高清核对）/ `low`（量级可信，位数存疑）。`图面转录` 与 `图面计算` 不必标。

> **为什么不直接二分为"有／无"**：课件缩图分辨率低，二分法会逼分析者在"猜"和"全弃"之间选。三档置信度把"我知道它大概是多少但不敢写死"这种真实状态如实保留下来，同时禁止它进入任何结论。

## 7. 数据字典必备十项

每份 `CASE-xxxx-数据字典.md` 至少包含：

1. 文件清单与行列数（含是否含表头）
2. 字段表：字段名 / 类型 / 含义 / 单位 / 约束
3. 主键与去重规则
4. 最小记录单位（一行代表什么）
5. 统计期与统计边界（哪一年、哪一范围）
6. 来源与 URL、采集日期
7. 清洗与换算规则（如 `1 trillion = 1000 billion`）
8. **事实 / 复原 / 不可推断** 三分清单
9. 缺失值清单：哪些格为空、为何为空
10. 复算式（至少一条）
11. **可数单元与计数结构判定**（v1.2.0 新增）：这张图能不能靠"数图形"还原数据？须逐条过 [计数结构筛查](计数结构筛查.md) §1 的四问（等大／固定单位／可数／可变），并给结论。即使判 `none` 也必须写——`none` 有两种，"本来无数值"与"有值但读不出"，只有写清可数结构才能区分。

## 8. 与模板、索引的接口

**案例分析模板 front matter** 新增三个字段，缺一不可：

```yaml
dataset_status: none            # complete | partial | none
dataset_path: ""                # partial/complete 必填，同目录文件名，如 "基础数据集.csv"
dataset_dict: ""                # 一律必填，如 "数据字典.md"
```

**案例索引**新增「数据表」列，取值 `完整` / `部分` / `无`，与 `dataset_status` 一一对应；点击进入数据字典。

**写 A 节的顺序**改为：先建表 → 再写 A。表是 A 的事实来源，不是 A 的附件。

## 9. 校验规则（脚本自动执行）

`scripts/validate_repo.py` 对每条 CASE 检查：

- `dataset_status` 必须是三档之一；
- `partial` / `complete` → `dataset_path` 指向的 CSV 存在，且 `dataset_dict` 指向的字典存在；
- `none` → `dataset_dict` 必须存在（`dataset_path` 可空）；
- CSV 表头不得含 `$`、`%`、空格，且不得出现 `value` 与单位混写的列名（如 `revenue($bn)`）；
- CSV 每行列数与表头一致；
- 字典必须含「不可推断」「复算」两项实质内容。

**存量豁免已取消（v1.2.0）**：v1.0.0 上线时 16 案中有 14 案未声明 `dataset_status`，脚本曾以 `WARNING` 列出、不计入失败。2026-11-24 十六案字典补全后，豁免段落已删除——现在缺 `dataset_status`、缺字典、字典缺「不可推断／复算／计数结构」任一项，一律报 `ERROR`。

判据始终是"有没有声明"，不是"在不在豁免名单里"。这也是为什么当初不写死名单：名单会让规范退化成白名单，而"必须声明"会让每一条新案例都自动受约束。

## 11. 与 V3 原文的差异（透明记录）

| V3 原文 | 本库做法 | 理由 |
|---|---|---|
| 一图一目录 `CASE-xxxx-作品名/`，原图、分析、CSV 同目录 | **已对齐**（2026-11-24）：`<类型>/案例/CASE-xxxx-名/`，图、分析、表、字典同处一室 | 结构迁移后不再有差异；早期曾用三目录平行方案，因"拷走一个案例会丢数据表"而放弃 |
| 每案必含 `基础数据集.csv` | 按 `dataset_status` 三档，`none` 只建字典 | 14 案无可转录数值，空表无信息量且会掩盖"为何无值"这个真问题 |
| 来源四级（转录／计算／补充／缺失） | 五级，增「图面可辨」 | 课件缩图分辨率低，二分会逼人猜；加一级把不确定如实留在表里 |
| 未规定置信度 | 增 `confidence`（high/mid/low） | 同上 |
| 未规定编码 | 统一 UTF-8 with BOM | Excel 直开中文不乱码 |
| 未规定校验 | 纳入 `validate_repo.py` + CI | 本库已有自动化，规范不落地就会退化 |

> 保留 V3 的全部**实质**：原子字段、单位分离、可溯源、禁止臆造、区分事实与推断、字典十项、一图一目录。放弃的只有**强制空表**这一条形式要求。
