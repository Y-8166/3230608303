# 案例分析模板（复制后创建独立 CASE 文件）

> 本文件是**空白模板**，不是案例。每张用户提供的案例图对应一个目录 `<类型文件夹>/案例/CASE-0001-标题/`，主文件为 `分析.md`。`CASE ID`、图片证据、数据内容必须来自真实材料。
>
> **v0.2.0 起，数据表是必填项**：先按 [数据表规范](数据表规范.md) 建表，再写 A 节。表是 A 的事实来源，不是附件。

```yaml
---
case_id: CASE-0001
case_title: 待填写
status: pending-analysis
received_at: YYYY-MM-DD
source_title: 待填写
source_url: ""
image_path: "原图.webp"  # 图片存本目录时填此名；无图则留空
license_or_permission: 待核实
analysis_version: 0.2.0
logic_primary: 未判定
logic_secondary: []
type_primary: 未判定
type_secondary: []
confidence: 未判定
dataset_status: none            # complete | partial | none，见 数据表规范 §2
dataset_path: ""                # partial/complete 必填，如 "基础数据集.csv"
dataset_dict: ""                # 一律必填，如 "数据字典.md"
---
```

### 三档数据状态怎么选

| 状态 | 判据 | 要做什么 |
|---|---|---|
| `complete` | 图面观测能全部转录，或已由官方数据补齐，且能复算图上关键结论 | 建 `基础数据集.csv` + `数据字典.md`，关键结论给复算式 |
| `partial` | 只能转录一部分，其余读不出 | 同上，空格留空由 `value_status` 说明，字典列"不可推断清单" |
| `none` | 图面本来就不承载数值（纯示意/纯定性/纯版式） | 只建 `数据字典.md`，写明"为何无值"与"禁止推断清单"，**不建空 CSV** |

> 拿不准时先按 `partial` 建表：把能读的读出来，读不出的标 `缺失`。这比先判 `none` 再回头补更省事。

## 0.1 基础数据集（V3 强制）

> 完整规则见 [数据表规范](数据表规范.md)。本节只列**必须落地的动作**。

**先建表，再写 A–E**。按图形性质选一种表形：

**A. 观测型**（一行一个观测对象：一个都市圈、一个县、一个阶段、一个人物）

```csv
obs_id,label_en,label_zh,metric_a,metric_b,unit,evidence_level,confidence,value_status,note
```

**B. 指标型**（一行一个指标，适合多面板混合图、图注指标）

```csv
metric_id,panel,panel_period,metric_label_en,metric_label_zh,value,unit,denominator,evidence_level,confidence,value_status,note
```

**建表后逐项自检**：

- [ ] 一行一个最小观测，一列一个属性，一格一个值（§4 规则 1）
- [ ] 数值格内无 `$`、`%`、`billion` 等字符串，单位进字段名或 `unit` 列（规则 2）
- [ ] 百分比为 0–100 纯数字，字段带 `_pct`，分母入 `denominator`（规则 3）
- [ ] 每个值都在 `evidence_level` 五级中有一档（§6）
- [ ] 读不出的格留空，由 `value_status=not_readable` 说明；**不写 `N/A`/`-`/`0`/`?`**
- [ ] 同步建 `数据字典.md`，十项齐全（§7），至少一条复算式
- [ ] 回填 front matter 的 `dataset_status`、`dataset_path`、`dataset_dict`

## 3. 提炼的设计方法与适用边界

**观察**：作品确实这样做了什么？

**解释**：这样做为什么可能有效？还有哪些解释？

**候选方法**：可迁移的制作步骤是什么？

**风险与反例**：在哪些数据类型/读者条件下不适用？

**证据级别**：单例观察 / 跨例模式 / 已发现反例 / 待核实。

### 3.1 制作流程与质量复核

**必须区分两件事**，不能把可复刻流程冒称作者的实际制作过程：

| 栏位 | 写什么 | 不许写什么 |
|---|---|---|
| 作者实际做法（图面可证） | 能从图面证据推出的操作，如"用同色色带表示连续覆盖" | "作者先用 Excel 汇总再导入 AI" |
| 作者实际做法（不可证） | 明写"图面无法证明" | 任何工具链、工时、访谈信息的猜测 |
| 本库可复刻重建流程 | 六步：采集 → 清洗 → 聚合/计算 → 编码 → 排版叙事 → 校验 | 把六步当成作者做过的六步 |
| 质量复核 | 逐项对照 §0.1 自检表与数据字典十项 | 只写"已核对" |

**复刻流程的六步各写一句可执行的话**，例如"清洗：营收统一换算为 `USD billion`，`1 trillion = 1000 billion`，保留原图一位小数"。

## PDF课件示例录入补充

新案例若来自教学PDF，写明PDF文件名、PDF实际页码、案例处在该页哪一幅（左/右/上/下），并区分"课件栏目归类"和"独立的数据逻辑判定"；没有高清原作和数据时，source_url、数值、作者、版权写待核实，不要将课堂缩图当成可自由使用的素材。

**课件缩图的数据表特别约定**：缩图分辨率不足时，多数案例只能判 `partial` 或 `none`。

- 能读的读数照抄，标 `图面可辨` + `confidence`；不要因为整图不清就整表放弃。
- 图例刻度、坐标轴端点、图注总量（如"员工 258 人"）通常可读，优先转录——它们往往正是复算的锚点。
- 逐县、逐企业、逐条目的细粒度值通常不可读，**不要逐格猜**；在字典"不可推断清单"里一次性写清"哪一级粒度不可得"，而不是留一堆 `?`。
- 缩图色值只能作近似取样用于形式重建，标 `图面可辨` 并说明"非原始设计色值"，不得当作事实统计。
