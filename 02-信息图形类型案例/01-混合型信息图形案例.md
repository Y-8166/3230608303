## 0. 类型定位：混合型为什么不是"第六类"

混合型（Mixed Charts）**不是与五类并列的第六种数据逻辑**，而是五类逻辑中任意 **≥ 2 种叠合**后形成的集成形态。它的必要性来自一个现实：真实的信息议题很少只服从一种组织逻辑（"某产品十年间的全球销量与产地变迁"同时是编年、地理、层级）。

它与"数据可视化"的分野正在这里：

| 维度 | 数据可视化（Data Visualization） | 混合型信息图形（Mixed Infographics） |
|---|---|---|
| 目的 | **探索与准确传达**数据关系 | **论证与说服**，让读者记住一个结论 |
| 图形角色 | 统计图形即终点 | 统计图形只是**骨架**，其上还要加视觉叙事与视觉编码 |
| 符号使用 | 极少（点线面足够） | 大量使用 **ISO 图形、象形符号、插画、示意图** |
| 数据密度 | 高（尽量不损失） | 中低（主动取舍，为叙事让路） |
| 装饰 | 视为噪声（chartjunk） | 视为**语义载体**（装饰必须承担编码功能） |
| 真实性约束 | 刻度、比例严格 | 允许**非等比示意图**，但必须声明 |
| 典型载体 | 仪表盘、论文图、BI 报表 | 海报、杂志跨页、年报、展板、长图 |

**一句话**：数据可视化把数据画准；混合型信息图形把数据**画成论点**。前者考的是统计素养，后者考的是编辑判断 + 图形语法。

## 1. 混合的四种合法方式

不是任意拼接都叫混合型，只有以下四种叠合关系成立：

| 方式 | 结构 | 例子 |
|---|---|---|
| **骨架 + 量值** | 一种逻辑作主轴，另一种统计图形挂在轴上 | 时间轴 + 折线（编年 × 统计） |
| **空间 + 事件** | 地理底图 + 编年锚点 | 行军图、迁徙史、灾害复盘 |
| **分解 + 比例** | 层级结构 + 面积/条形 | 剖层图、架构爆炸图、预算分解 |
| **图鉴 + 比较** | 编目网格 + 单元格内统计图形 | 参数对比图鉴、车型图录 |

**非法混合**（常见错误）：
- 三套坐标系叠在同一张图上而无视觉分隔（读者无法判读归属）；
- 同一视觉通道（如面积）同时编码两个不同维度；
- 装饰符号与数据无对应关系（"为了好看"加的图标）。

## 2. 混合型的通用视觉语法

以下五条是从各类优秀混合图形中反复出现的规律，构成本类型的**制作公理**：

### 2.1 单一锚定原则
一张混合图**只能有一个视觉锚**——通常是那条贯穿全图的主轴（时间轴 / 地理边界 / 结构中心线）。所有其他元素都必须"挂"在这个锚上，共享同一坐标系或同一基线。**两个锚 = 两张图**，应拆分或用明确的分隔框。

### 2.2 图层递减原则
自下而上固定为：`底图/骨架 → 数据层 → 符号层 → 注记层 → 叙事层`。每上一层的视觉重量必须低于下一层。检验：眯眼看图，最先看到的必须是骨架，而不是插画。

### 2.3 尺度诚实原则
统计图形部分（条形长度、折线刻度、面积比例）**必须真实**；只有非数据性的示意部分（如人物插画、路径弯曲）可以失真。**"统计部分失真"是混合型最常见的失格方式**——一旦读者发现条形不按比例，整张图的可信度归零。

### 2.4 符号语义原则
每一个 ISO 图形/象形符号必须满足二者之一：
- **可数**（一个符号 = 固定基数），或
- **可辨**（形状编码类别）。
不可两者皆无（纯装饰）。装饰性符号总量应 ≤ 符号总数的 20%。

### 2.5 一处高潮原则
混合型因元素多，最容易"处处用力"。必须用 **留白 + 唯一强调色 + 最大符号** 三者共指一个焦点，其余区域统一降饱和。

## 6. 制作工序（七步）

1. **定论点**：写出一句可被反驳的判断。写不出则不进入绘制。
2. **选骨架**：从五类逻辑中选一个作主轴（多数情况是编年或地理）。
3. **搭统计层**：确定借用的统计图形、刻度、分级、归一化方式。
4. **换编码**：把统计图形的默认样式替换为视觉编码（符号化、色阶化、图标化）。
5. **排叙事**：定阅读路径、起转合、唯一高潮位置。
6. **压信息**：执行折叠（主轴节点 ≤ 7、图例 ≤ 5、文字 ≤ 250 字）。
7. **校诚实**：逐条核对"统计部分比例真实""刻度已声明""口径与来源已标"。
