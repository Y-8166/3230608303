## 0. 类型定位：混合型为什么不是"第六类"

混合型（Mixed Charts）**不是与五类并列的第六种数据逻辑**，而是五类逻辑中任意 **≥ 2 种叠合**后形成的集成形态。第三讲把它列在 3-6「常用信息图形种类」的首位（p.22），正是这个意思——它属于**形式层**，不属于**逻辑层**。

它与"数据可视化"的分野正在这里：

| 维度 | 数据可视化（Data Visualization） | 混合型信息图形（Mixed Infographics） |
|---|---|---|
| 目的 | **探索与准确传达**数据关系 | **论证与说服**，让读者记住一个结论 |
| 图形角色 | 统计图形即终点 | 统计图形只是**骨架**，其上还要加视觉叙事与视觉编码 |
| 符号使用 | 极少（点线面足够） | 大量使用 **ISO 图形、象形符号、插画、示意图** |
| 数据密度 | 高（尽量不损失） | 中低（主动取舍，为叙事让路） |
| 装饰 | 视为噪声（chartjunk） | 视为**语义载体**（装饰必须承担编码功能） |
| 真实性约束 | 刻度、比例严格 | 允许**非等比示意图**，但必须声明 |
| 典型载体 | 仪表盘、论文图、BI 报表 | 海报、杂志跨页、年报、展板、长图 |

**一句话**：数据可视化把数据画准；混合型信息图形把数据**画成论点**。前者考的是统计素养，后者考的是编辑判断 + 图形语法。

> 补充：第三讲 p.31 的「单一图表型（Single chart）」正是这条分界线上的临界样本——同一张图，不加叙事即属数据可视化；加了标题主张、注释、强调色与视觉层级，才成为信息图形。

## 1. 混合的四种合法方式

不是任意拼接都叫混合型，只有以下四种叠合关系成立：

| 方式 | 结构 | 例子 |
|---|---|---|
| **骨架 + 量值** | 一种逻辑作主轴，另一种统计图形挂在轴上 | 时间轴 + 折线（编年 × 统计） |
| **空间 + 事件** | 地理底图 + 编年锚点 | 行军图、迁徙史、灾害复盘 |
| **分解 + 比例** | 层级结构 + 面积/条形 | 剖层图、架构爆炸图、预算分解 |
| **图鉴 + 比较** | 编目网格 + 单元格内统计图形 | 参数对比图鉴、车型图录 |

**非法混合**（常见错误）：
- 三套坐标系叠在同一张图上而无视觉分隔（读者无法判读归属）；
- 同一视觉通道（如面积）同时编码两个不同维度；
- 装饰符号与数据无对应关系（"为了好看"加的图标）。

## 2. 混合型的通用视觉语法

以下五条是从本库已归档案例中反复出现的规律，构成本类型的**制作公理**：

### 2.1 单一锚定原则
一张混合图**只能有一个视觉锚**——通常是那条贯穿全图的主轴（时间轴 / 地理边界 / 结构中心线）。所有其他元素都必须"挂"在这个锚上，共享同一坐标系或同一基线。**两个锚 = 两张图**，应拆分或用明确的分隔框。

### 2.2 图层递减原则
自下而上固定为：`底图/骨架 → 数据层 → 符号层 → 注记层 → 叙事层`。每上一层的视觉重量必须低于下一层。检验：眯眼看图，最先看到的必须是骨架，而不是插画。

### 2.3 尺度诚实原则
统计图形部分（条形长度、折线刻度、面积比例）**必须真实**；只有非数据性的示意部分（如人物插画、路径弯曲）可以失真。**"统计部分失真"是混合型最常见的失格方式**——一旦读者发现条形不按比例，整张图的可信度归零。

### 2.4 符号语义原则
每一个 ISO 图形/象形符号必须满足二者之一：
- **可数**（一个符号 = 固定基数），或
- **可辨**（形状编码类别）。
不可两者皆无（纯装饰）。装饰性符号总量应 ≤ 符号总数的 20%。

### 2.5 一处高潮原则
混合型因元素多，最容易"处处用力"。必须用 **留白 + 唯一强调色 + 最大符号** 三者共指一个焦点，其余区域统一降饱和。

## 4. 案例解析

### CASE-M-001 ｜ 企业可持续发展年报图版

**图版**：第三讲 p.22（Environmental Stewardship / Transportation / Client Satisfaction / Workplace 四栏）
**出处**：企业年度可持续性报告类图版，2010–2011 两期对比
**议题**：让读者相信"公司在四个维度上都比上年更好"

**① 数据逻辑拆解**
- 主逻辑（骨架）：**编目型**——四个主题并列成四栏，每栏内指标逐项登记
- 辅逻辑：**统计图形**——条形、环图、分箱直方图、象形阵列
- 时间维度：并非完整编年轴，只以"本年 vs 上年"的**两期并置**存在
- 混合方式：方式四（图鉴 + 比较）

**② 统计图形部分**
- 借用：水平条形（强度比较）、环图 donut（占比）、等宽分箱直方图（通勤距离分布）、象形人或圆阵列（人数与工时）
- 刻度：条形均从零起，等比；直方图分箱等距（5 km 一档）
- 计算：两期同比（本年／上年）、占比、分布分箱

**③ 视觉编码**
- 点：象形人形图标阵列，用于表达员工数量
- 线：无坐标轴，条长即量
- 面：四栏等宽分区，浅青绿底 + 留白分隔，无竖线
- 体：无
- 符号：叶子／水滴／火焰／闪电／汽车等线性图标，**只表类别**（能源、水、交通）
- 色彩：单色系（青绿阶），深浅区分"本年／上年"；绿色点缀表"改善"
- 文字：指标名用小型大写 + 字距加宽；数值大号粗体；上年值置于括号内、小号浅色

**④ 数据/信息架构**
- 层数：栏目名 → 指标组 → 指标 → 数值对 → 微型图（五层）
- 视觉锚：无单一锚，四栏**平行锚**
- 折叠手法：只取两期，放弃完整时间序列——用"对比"替代"趋势"
- 信息配额：4 栏 × 3–6 指标；无图例；文字约 300 字

**⑤ 视觉叙事架构**
- 阅读路径：Z 字形（左→右四栏，栏内自上而下）
- 叙事模式：分布式（年报式平铺，无强转折）
- 起·转·合：仅"起"（栏目名建立契约）；**无转、无合**
- 唯一高潮：**缺失**——这既是它的稳健，也是它的弱点

**⑥ 可复用要点**
1. **"大数 + 括号内上年数"是零成本的对比装置**：不必再画第二张趋势图，读者即刻获得方向感。
2. **每栏内保持同一微型图语法**（指标名→图→数），读者学会一次即可通读四栏，降低跨栏切换成本。
3. **图标只表类别，数量交给条形**——避免"图标大小"与"条形长度"两个通道争夺同一维度。

**⑦ 问题与风险**
- 象形人形阵列未标"1 图标 = N 人"，**无法读数**，违反 2.4 可数原则。
- 直方图纵轴无标签，"21% / 20%" 究竟是占比还是人数不明。
- 全篇只有栏目名，**没有一句可被反驳的主张**——属"数据堆放"而非论证。
- 绿色同时承担"品牌色"与"改善"两种语义，通道重叠。

### CASE-M-002 ｜ 宇宙航行图（COSMIC JOURNEYS）

**图版**：第三讲 p.37
**出处**：科普杂志跨页（National Geographic 风格），主题为太阳系探测任务
**议题**：让读者感受到"人类探测器已布满整个太阳系"

**① 数据逻辑拆解**
- 主逻辑：**编年**（底部时间轴 + 任务发射年份）
- 辅逻辑 1：**编目**（侧栏编号任务清单）
- 辅逻辑 2：**空间**（行星轨道作为定位骨架）
- 混合方式：课程 p.36/37 明确标为「编年图+编目混合图」，实为三重叠合

**② 统计图形部分**
- 借用：轨迹图（trajectory plot）——本质是极坐标下的路径线；底部为水平时间轴
- 刻度：底部时间轴等比（1957 起）；**轨道部分为等距示意，非真实比例**
- 计算：无统计计算；"数量"以线条密度隐式表达

**③ 视觉编码**
- 点：行星、卫星、探测器当前位置
- 线：**主角**。一条线 = 一次任务；线色 = 目标天体；**线密度 = 任务数量**
- 面：深空黑底——负空间即"空间"本身
- 体：无
- 符号：数字编号（①②③…）作为图与文之间的**索引键**
- 色彩：按天体分组色相（内行星红橙、木星土星蓝绿、外行星青紫），黑底令线条以发光形式呈现
- 文字：极小字号、极高密度

**④ 数据/信息架构**
- 层数：主图（轨道轨迹）／侧栏编目（编号 + 任务名 + 年份）／底部时间轴（三层）
- 视觉锚：太阳（左上角，唯一的向内收束点）
- 折叠手法：任务不逐个标注，改以编号外挂
- 信息配额：任务 > 150 条，编号列表 3 组，文字约 800 字

**⑤ 视觉叙事架构**
- 阅读路径：由内向外（太阳→海王星），再由上而下（底部时间轴）
- 叙事模式：中心—边缘式 + 分布式
- 起：太阳与内太阳系密集轨迹；转：木星／土星一带的轨迹爆发；合：底部时间轴末端的"仍在飞行"
- 唯一高潮：内太阳系那团红色密集轨迹（全图视觉密度峰值）

**⑥ 可复用要点**
1. **编号是混合图最便宜的多层索引装置**：图形放编号、侧栏放解释，读者按需跳跃，不必在图上塞长文字。
2. **用密度而非数值表达数量**：轨迹越密即任务越多，省掉一整套编码。
3. **一张图允许两套坐标系**（轨道极坐标 + 底部线性时间），前提是用版面对半切开、各有自己的轴标签。

**⑦ 问题与风险**
- 轨迹线远超可辨识上限（目测 > 150 条），**单条不可追踪**，密集区里"编号↔线条"的对应实际失效。
- 轨道比例非真实，却**未标注"示意图"**，违反 2.3 尺度诚实。
- 轨道图**不按时间排布**，而底部时间轴按时排布——两套时间语义并存，易误读为同一维度。
- 字号过小，屏幕缩放后不可读。

## 5. 归纳：目前可确立的规则

> 依据案例编号标注；无依据者标"待验证"。随案例增加持续改写。

| # | 规则 | 依据 |
|---|---|---|
| R1 | 混合图中，统计图形部分必须保持真实比例，示意部分才可失真 | M-001、M-002 |
| R2 | 允许非等比示意图时，须在图内显式标注"示意图，非等比" | M-002（反例：未标注） |
| R3 | 全图只允许一个视觉锚；第二个锚须拆图或以版面硬切分隔 | M-002（正例）、M-003（环／四角双区靠留白硬切） |
| R4 | 象形符号若表数量，必须标"1 图标 = N 单位"；不标则只能表类别 | M-001（反例） |
| R5 | 编号是混合图中唯一可无限扩展的文字外挂方式，优先于"图上塞字" | M-002 |
| R6 | 强调色 ≤ 2 色相，且不得同时承担"品牌"与"状态"两种语义 | M-001（反例：绿色语义重叠） |
| R7 | 两套坐标系共存时，必须各自具备独立轴标签，并以版面切分 | M-002 |
| R8 | 一张混合图若没有可被反驳的标题主张，则退化为"数据堆放" | M-001（反例） |

## 6. 制作工序（七步）

1. **定论点**：写出一句可被反驳的判断。写不出则不进入绘制。
2. **选骨架**：从五类逻辑中选一个作主轴（多数情况是编年或地理）。
3. **搭统计层**：确定借用的统计图形、刻度、分级、归一化方式。
4. **换编码**：把统计图形的默认样式替换为视觉编码（符号化、色阶化、图标化）。
5. **排叙事**：定阅读路径、起转合、唯一高潮位置。
6. **压信息**：执行折叠（主轴节点 ≤ 7、图例 ≤ 5、文字 ≤ 250 字）。
7. **校诚实**：逐条核对"统计部分比例真实""刻度已声明""口径与来源已标"。

> 与第三讲 p.43 四步流程的对应：第 1–2 步 = B「数据集与结构搭建」，第 3–5 步 = C「视觉编码与版式排布」，第 6–7 步 = D「数据关联与内容呈现」。完整方法论见 [03-信息图形方法论](../03-信息图形方法论/02-设计流程与评估.md)。
