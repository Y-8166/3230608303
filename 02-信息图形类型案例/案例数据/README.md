# 案例数据目录

本目录存放 `CASE-xxxx` 的**结构化数据表与数据字典**，与 [`../案例记录/`](../案例记录/)（分析正文）、[`../案例图/`](../案例图/)（图版）三足并列。

规则见 [数据表规范](../数据表规范.md)。这里只重复三条最容易出错的：

1. **文件名前缀必须与案例记录同号**：`CASE-0007-多主题混合统计.md` → `CASE-0007-基础数据集.csv`。
2. **CSV 一律 UTF-8 with BOM**，Excel 双击直开不乱码；换行 `LF`；首行为表头。
3. **不建空壳**：`none` 状态只建字典，不建只有表头的 CSV；`partial` 允许基础表为空行，但字典必须解释为什么空。

## 文件类型

| 文件 | 何时建 | 内容 |
|---|---|---|
| `CASE-xxxx-基础数据集.csv` | `complete` / `partial` | 作品呈现的观测数据。一行一个最小观测，一列一个原子字段 |
| `CASE-xxxx-辅助指标.csv` | 有图注指标、图例刻度、画布事实时 | 不属观测数据但支撑复算的量 |
| `CASE-xxxx-数据字典.md` | **一律必建** | 字段、粒度、统计期、来源、事实/复原/不可推断、缺失清单、复算式 |

## 本目录不做什么

- **不放图**。图版只能在 [`../案例图/`](../案例图/)，全库图片检查由 `scripts/validate_repo.py` 强制执行。
- **不放分析正文**。A–E 五维仍写在 [`../案例记录/`](../案例记录/) 的 Markdown 里，CSV 只提供数据骨架。
- **不放中间过程文件**。裁剪图、OCR 原始输出、脚本临时结果不进版本库。
