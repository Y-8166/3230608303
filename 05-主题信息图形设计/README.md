# 05 主题信息图形设计 · 八阶段工作流

> **本目录定位**：把前四层（逻辑／类型／方法／工具）落成一张**真实作品**的项目台。
> **用法**：定题后把「XXX」替换成你的题目（目录名不必改，内部文件改写研究对象即可），逐阶段填写，每阶段的材料与修改记录**就地更新**，不新建"修订版"文件。
> **判断依据始终在别处**：这一层负责"做"，不负责"定义"——类型判定回 [02-类型总览](../02-信息图形类型案例/00-类型总览.md)，逻辑判定回 [01-数据逻辑](../01-信息图形数据逻辑/)，方法疑问回 [03-方法论](../03-信息图形方法论/)。

## 阶段与产出

| 阶段 | 本阶段要回答的问题 | 完成标志 |
| --- | --- | --- |
| [01 前期调研](01-前期调研/README.md) | 想讲清什么，给谁看，使用情境是什么？ | 一句话主张 + 读者画像 + 使用场景 |
| [02 主题内容分析](02-主题内容分析/README.md) | 数据怎样组织，作品采用哪些表现类型、视觉风格和图表标签？ | 参照作品拆解表（含类型与逻辑归属） |
| [03 数据搜集](03-数据搜集/README.md) | 去哪里找数据、文献和图像，各来源能回答什么？ | 来源清单 + 可用性判断 |
| [04 基础数据集构建](04-基础数据集构建/README.md) | 每行代表什么，怎样做到每个单元格只放一个数据？ | 一行的定义 + 字段字典 + 缺失值处理 |
| [05 叙事框架搭建](05-叙事框架搭建/README.md) | 哪些字段合在一起可以讲清一个具体问题？ | 分镜式叙事骨架（每屏一个问题） |
| [06 视觉编码](06-视觉编码/README.md) | 如何用图形、色彩、版式与图像表达数据关系和阅读顺序？ | 编码方案表（通道 → 变量 → 刻度） |
| [07 信息轮盘测试](07-信息轮盘测试/README.md) | 读者能否复述主题、指标、比较与事实/观点界限？ | 测试记录（对象、任务、结果） |
| [08 设计实施](08-设计实施/README.md) | 用什么形式交付，怎样把叙事和编码落实到成品？ | 交付物 + 自检清单 |

> **不可跳的两步**：04（数据集的"一行是什么"没定死，后面全部返工）与 07（没测过就不知道读者读到了什么）。其余阶段可根据项目体量压缩。
