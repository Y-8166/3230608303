# 03 ISOTYPE 信息图

> 一句话：**用重复的等大图符数数量**——一套方法，不是一种图形类型。

本层原为 `02-信息图形类型案例/18-ISOTYPE-基础设计方法`（第 18 项类型标签）。2026-11-24 升为顶层板块，理由见 §1。

## 1. 为什么独立成层

在 02 层时，ISOTYPE 被排在第 18 位，与"混合型""时间轴型"并列。这个位置是错的，因为那 17 项是**形态**（长成什么样），ISOTYPE 是**方法**（怎么把数据变成图形）。两者不在一个维度上：

- 一张比较型信息图可以是 ISOTYPE 式（用图符数人数）；
- 一张 ISOTYPE 式作品也可以是比较型、单图表型或混合型；
- 反过来，一张用满象形图标的图，若没有"1 图标 = N 单位"的计数结构，**不是** ISOTYPE。

把方法与形态并列，会导致两个后果：查类型时误以为 ISOTYPE 是第 18 种形状；标注案例时把"用了图标"当成"用了 ISOTYPE"。独立成层就是为了切断这个混同。

模板库（`fengbaifan/Infographic-Style-Repository`）同样把 ISOTYPE 单列为 03，本层的层级位置与之一致；但该库 03 下的四个专题目录均为占位说明，本库只建有实质内容的两份文档，不复制空骨架。

## 4. 与 02 层的关系

一张图可以同时有两个标签，各填一处：

```
表现类型（形态）：比较型        → 记在 02/06-比较型-Comparison/
设计方法（方法）：ISOTYPE 式     → 记在本层
```

判断顺序建议：**先判形态，再判方法**。因为形态看轮廓就能定，方法要读图例、数图符才能确认。反过来先判方法，容易把"看起来像象形图"的作品误标。

## 5. 案例现状

截至 2026-11-24：**0 条**。

16 条课件案例逐条检查过，没有一条具备"1 图标 = N 单位"的计数结构。它们多是插图式（CASE-0015 宇宙旅程）、编目式（CASE-0004 绘画编目）、单图表式（CASE-0007 多主题统计）——用了图形，但没有用图形**计数**。

这不等于本层没有价值。恰恰相反：正因为课件里没有合格样本，才需要把判定门槛写死（[00](00-ISOTYPE概念与方法.md) 的三条硬规则 + [01](01-图符语言与视觉编码.md) 的九条自检），否则以后遇到"看起来像"的图，没有依据说它像不像。
