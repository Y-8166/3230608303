## 三条通用操作建议（来自 00 总览 §6.4，经验值待验证）

- 同一条目内**只用一种分组信号**：同时用"近＋同色＋同框"，读者会读出三个组，而不是一个组。
- 表达**层级**用共同区域（框套框），不用加大间距——间距读到的是"无关"。
- 表达**归属**用元素连接（引线），不用同色——同色读到的是"同类"。

## 写进本库的规则

1. **先做完再记**：完成一个作品后才记录实践流程、失败版本与可复用经验；不预填"建议"冒称已测结论。
2. **标清证据等级**：图像观察／设计推断／真实受众测试三类分开写，不混为同等强度的事实。
3. **对照才有结论**：调整前后的效果必须来自 [03 对照实验](../03-跨原则对照实验/README.md) 的两版素材，或明确标"未测"。
4. **改一处**：经验正文只改 `01-规则库/` 里对应文档的 E 段，本页索引不动。
