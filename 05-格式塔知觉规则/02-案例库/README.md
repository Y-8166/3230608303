## 为什么单列这个分区

参考库把"真实案例"与"规则文档"分开：规则只按证据关联，原图全局只归档一次。本库沿用这个分工，但案例实体在 02 层，所以本分区承载的是**按原则反查**的转置索引——回答"想验证接近律，该看哪几个案"。

## 已知覆盖缺口

- **03 共同命运、08 广义共同命运、09 同步性**：16 案全为静态课件图，三条动态原则**没有动态正例**，只能靠交互原型补证。
- **06 对称**：没有严格镜像案例（人口金字塔／蝴蝶图）。
- **07 平行**：只有近似样本（版式平行），缺真实并行数据。

> 缺口来自 [99 附录 §4](../99-证据分级与待办.md)，不是新判读。补齐前不得把"近似样本"写成"已验证正例"。

## 新增关联的三步

1. 在 02 层对应类型文件夹下按 [案例分析模板](../../02-信息图形类型案例/案例分析模板.md) 建案，图片与数据表同目录。
2. 在 [00 总览 §8](../00-总览与索引.md) 加一行"案 → 原则"，再在本表对应原则行补案号。
3. 跑 `python scripts/validate_repo.py`，确认链接与锚点全通。
