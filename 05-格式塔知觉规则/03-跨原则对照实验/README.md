## 三条已确认的经验（有文献支撑，非本库实测）

| 关系 | 结论 | 依据 |
|---|---|---|
| 共同区域 vs 接近 | 共同区域可压过接近：区域内更远的点，仍比区域外更近的点更"同组" | Palmer 1992（对照实验） |
| 元素连接 vs 接近 | 连接通常强于接近：被线连起来的点即使更远，也被看成一对 | Palmer & Rock 1994 |
| 接近 vs 相似 | 取决于差异量级，无固定胜者 | Wertheimer 演示与后续复现 |

**不能排成一条全序**——不存在"接近永远压过相似"。强度取决于差异量级、通道与任务。

## 为什么必须做对照实验

同一批元素常同时给出两条互相矛盾的线索。典型例子：**图注离左图更近（接近 → 左），却落在右图的浅色底板内（共同区域 → 右）**。读者不会比较"哪条规则更强"，而是选**描述成本最低的整体读法**——冲突结果无法纯靠推理预判，只能测。

## 四步测试法（摘要）

1. **做两版**：完全相同的素材（同图、同字、同色），只改一个变量（间距或边界）。
2. **只调一个**：第二版不得同时改颜色、字号或位置，否则测的是"哪版更好看"。
3. **问一个封闭问题**："这段图注属于哪张图"，不问"你觉得清楚吗"。
4. **记录误配位置**：不只对错，要记错在哪一对元素之间。误配分布就是冲突的位置。
