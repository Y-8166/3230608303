# 07 ｜ 平行性 Parallelism

> **概念定义（课程口径）**：并排延伸、方向相近的线或轮廓容易被视为相关。
> **信息图形设计示例（课程口径）**：用两条平行轨道组织并行流程。
> **一句话**：并排走的两条线，读成"一对相关的通路"。
> **证据**：现代增补（Kubovy & Wagemans 1995）｜C 节数值均为经验值（待验证）
> **导航**：14 条之 7 ｜ [总览](00-总览与索引.md) ｜ 上一篇 [对称律](06-对称律-Symmetry.md) ｜ 下一篇 [广义共同命运](08-广义共同命运-Generalized-Common-Fate.md)

## A 概念定义

### A.1 课程定义（逐字保留）

> 并排延伸、方向相近的线或轮廓容易被视为相关。

"**并排**"与"**方向相近**"是两个条件。只满足一个不算：两条线方向相同但相距很远，读成"碰巧同向"；两条线挨得很近但夹角 40°，读成"交叉"。

### A.2 原始文献表述

平行不在 Wertheimer 1923 的因子清单里。它作为独立分组线索，主要由 Kubovy 与 Wagemans 在点阵实验（1995）中提出并量化：在规则点阵中，除了接近与相似，**沿同一方向的排列**本身就是一个可测量的分组力量。因此本条标为**现代增补**，证据强于"设计经验"，但弱于"原始文献"。

### A.3 可操作版（判定式）

两条（或多条）线／轮廓若**夹角小**且**间距稳定**，读者把它们读成"同一族的并列通路"——相关、可对照、地位相当。

判定式：夹角 ≤ 10° 读成平行；10°–20° 读成"大致同向"（需要别的线索支持）；> 20° 读成交叉或发散。间距波动 ≤ 20% 才读得出"轨道感"。

### A.4 边界：它与相邻三条的分工

| 规则 | 关系 | 一句话 |
|---|---|---|
| **07 平行性**（本条） | 两条线**同向并排** | "它们是并列的两条路" |
| [04 良好连续律](04-良好连续律-Good-Continuation.md) | **一条线**自己顺着走 | "这是同一条路" |
| [06 对称律](06-对称律-Symmetry.md) | 两条线**镜像** | "它们是一对，且对等" |
| [02 相似律](02-相似律-Similarity.md) | 属性相同，无方向要求 | "它们同类" |

平行比相似强在**有方向承诺**：一旦并排，读者会默认两条线"同步前进"，一条断了另一条也该断。

## B 知觉机制

平行是"方向相似"的几何化。视觉系统对朝向高度敏感（朝向通道独立于位置通道），因此"同向"可以在很远的距离上被检出——这让平行成为一种**跨空间的绑定**，比接近更能跨越版面。

## C 编码手段

| 场景 | 做法 | 参数（经验值，待验证） |
|---|---|---|
| 并行流程（泳道） | 两条泳道等宽、同起点、同终点 | 泳道宽差 ≤ 5%；起终点对齐 |
| 轨道／线路 | 平行段间距恒定，交叉处直穿 | 夹角 0°；间距波动 ≤ 20% |
| 并列条形 | 同基线、同间距、同条宽 | 条宽一致，组距一致 |
| 平行坐标图 | 轴等距垂直排列，折线跨轴 | 轴数 ≤ 8；折线透明 ≤ 40% |
| 双轨时间轴 | 两条时间轴用同一刻度、同一总长 | 刻度完全对齐 |
| 对照版式 | 两栏等宽，标题同行高 | 栏宽差 ≤ 5% |

**关键**：平行一旦成立，读者会**自动对齐**——把左轨的第 3 个节点与右轨的第 3 个节点配成一对。所以两条轨道的**节点数必须相等**，否则读者会在缺失处"填空"。

## D 信息图形设计示例与案例

### D.1 课程示例拆解：两条平行轨道组织并行流程

> 用两条平行轨道组织并行流程。

这条示例解决的是"两条时间线同时发生"的排版难题：如果上下堆叠，读者要来回跳；如果画成一张网状图，读者跟丢。平行轨道给出第三条路：

1. **同起点同终点**：两条轨道共享起止刻度，读者一眼确认"这两条覆盖同一时段"；
2. **节点一一对应**：同一时刻在两轨上处于同一横坐标，读者可以竖向扫；
3. **关系靠连接线**：需要表达"这一节点触发那一节点"时，才加一条竖向或斜向的短连接——**不靠颜色，靠几何**。

它的代价是：一旦两条轨道的节点密度差异过大（一条 3 个节点、一条 30 个），"平行"就退化成"两条不相关的刻度尺"。

### D.2 库内正例

**正例 1｜[CASE-0015 宇宙旅程混合图](../02-信息图形类型案例/15-编年编目复合型-Hybrid/案例/CASE-0015-宇宙旅程混合图/分析.md)**（课件 p.37）
可见事实：多条弯曲彩色路径并排延伸，底部有统一的时间注释。本库判读：多条路径之所以没有读成一团乱线，靠的是"并排＋同向"——它们被读成"同一旅程的几条并列线索"，而底部的统一时间注释进一步把它们钉在同一个参照上。

**正例 2｜[CASE-0007 多主题混合统计](../02-信息图形类型案例/01-混合型-Mixed-Charts/案例/CASE-0007-多主题混合统计/分析.md)**（课件 p.22）
可见事实：环境、交通、满意度、职场四个栏目并列排布，各栏内部结构相似。本库判读：四栏被读成"同一主题的四个面"，而非四张独立的图，靠的是**版式平行**（等宽、同基线、同栏距）。若栏宽不一或栏距跳动，读者会把它们读成四个独立模块。

### D.3 反例：伪平行（手绘示意里角度不一）

一张手绘风格的双轨示意里，两条"平行"流程线的夹角在 8°–25° 之间波动（画师凭手感）。读者的追踪在第三段失败：他无法判断"这个节点属于上轨还是下轨"，因为两轨在那里几乎相交。错在**把平行当成感觉而不是几何**。

修法：所有平行段用同一角度模板（0° 或统一斜角），间距用网格锁定；手绘质感可以保留在笔触上，**不能保留在几何上**。

## E 设计实践经验

- **平行是"承诺"。** 一旦并排，读者会默认两条线同步；一条中断必须给出对应标记，否则读者以为漏读。
- **节点数要对齐。** 两轨节点数不等时，读者会在空缺处臆造对应关系。
- **不要用平行表达"层级"。** 平行说"地位相当"，层级要靠缩进、框套框或分支线（[元素连接](11-元素连接-Element-Connectedness.md)）。
- **平行坐标图慎用。** 轴数超过 8 条、折线不透明，读者只会看到"一团交叉"——那时平行性已经失效，剩下的是噪声。
- **线索冲突**：两条线平行（7），但其中一条落在深色底板内（[图底](13-图形背景组织-Figure-Ground.md)／[共同区域](10-共同区域-Common-Region.md)）。读者会把深色底板上那条读成"更重要的那一条"，平行所暗示的"地位相当"被打破。修法：两条轨道给同一底色，或把"更重要"明确画成主线＋支线，而不是靠底色暗算。

## F 自检清单

- [ ] 平行段夹角是否 ≤ 10°？间距波动是否 ≤ 20%？
- [ ] 两条轨道的节点数、起止刻度是否对齐？
- [ ] 是否存在"看起来平行、实际不同角度"的手绘段？
- [ ] 是否在用平行暗示"地位相当"（而非层级）？
- [ ] 一条轨道中断时，是否有对应标记？
- [ ] 平行坐标图轴数是否 ≤ 8、折线是否足够透明？
- [ ] 与底板／底色冲突时，"地位相当"是否被打破？
