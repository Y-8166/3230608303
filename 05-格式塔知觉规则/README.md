## 14 条原则

| # | 原则 | 一句话 | 文档 |
|---|---|---|---|
| 01 | 接近律 Proximity | 相对距离较近的元素容易被看成一组 | [01](01-接近律-Proximity.md) |
| 02 | 相似律 Similarity | 颜色、形状或纹理相似的元素容易被归为一组 | [02](02-相似律-Similarity.md) |
| 03 | 共同命运律 Common Fate | 运动方式相近的元素容易被看成一组 | [03](03-共同命运律-Common-Fate.md) |
| 04 | 良好连续律 Good Continuation | 方向或曲率平滑衔接的线段容易被读为同一路径 | [04](04-良好连续律-Good-Continuation.md) |
| 05 | 闭合律 Closure | 轮廓虽有缺口，读者仍可能组织成完整形状 | [05](05-闭合律-Closure.md) |
| 06 | 对称律 Symmetry | 围绕同一轴呈镜像关系的部分容易被组织为一对或整体 | [06](06-对称律-Symmetry.md) |
| 07 | 平行性 Parallelism | 并排延伸、方向相近的线或轮廓容易被视为相关 | [07](07-平行性-Parallelism.md) |
| 08 | 广义共同命运 Generalized Common Fate | 可见属性同时沿同一方向变化，也可促成分组 | [08](08-广义共同命运-Generalized-Common-Fate.md) |
| 09 | 同步性 Synchrony | 同一时间发生的变化可提供分组线索，变化方向可以不同 | [09](09-同步性-Synchrony.md) |
| 10 | 共同区域 Common Region | 位于同一可见边界内的元素容易被视为一组 | [10](10-共同区域-Common-Region.md) |
| 11 | 元素连接 Element Connectedness | 独立元素被可见的线或形状连接后容易被读为一组 | [11](11-元素连接-Element-Connectedness.md) |
| 12 | 均匀连通性 Uniform Connectedness | 色彩、明度或纹理较均匀的连续区域容易被看作一个视觉单位 | [12](12-均匀连通性-Uniform-Connectedness.md) |
| 13 | 图形—背景组织 Figure–Ground | 一部分区域被读成有明确轮廓的主体，其余成为背景 | [13](13-图形背景组织-Figure-Ground.md) |
| 14 | 良好形态原则 Prägnanz | 知觉倾向形成较稳定、规整或关系较清楚的整体 | [14](14-良好形态原则-Pragnanz.md) |
