## 0. 一句话定义

**地理图形信息图形，是以真实空间位置（坐标、边界、路径、邻接）为组织骨架，把属性数据锚定在地理参照系上，从而回答"在哪、分布如何、从哪到哪、为什么在这里"的信息图形。**

它的独特性在于：**位置本身就是信息**。一张好的地理图形，删掉底图后数据就失去意义——这既是它的判据，也是它的风险（底图会同时带来政治、精度与投影三重约束）。

## A 基本的数据逻辑

### A.1 本质数据结构

地理图形的本质是**空间参照系 + 属性挂载**，即"几何 + 数据"的二元组：

```
geo[i] = { geometry, crs, attrs{...} }
```

| 要素 | 语义 | 说明 |
|---|---|---|
| `geometry` | 点 / 线 / 面 / 栅格 / 流 | 决定可用的图形谱系（见 B.1） |
| `crs` | 坐标参照系（经纬度 WGS84 / GCJ-02 / CGCS2000） | **必须与底图一致**，混用会产生数百米偏移 |
| `attrs` | 该几何承载的数值与类别 | 决定色彩/符号映射 |

五行几何形态，与数据的语义严格对应：

| 几何 | 数据签名 | 语义 | 图形产物 |
|---|---|---|---|
| **点**（Point） | `(lon, lat, value?, category?)` | 某地有某事 | 符号图、点密度、热力 |
| **线**（Line） | `[[lon,lat]...]` | 连接、路径、边界 | 流向图、路线图 |
| **面**（Polygon） | `[[[lon,lat]...]]` | 区域的整体属性 | 分级设色、变形图 |
| **栅格**（Raster） | `grid[r][c] = value` | 连续场（温度、密度） | 等值线、热力面 |
| **流**（OD Flow） | `(origin, dest, weight)` | A 到 B 的迁移量 | 流向图、弦线图 |

> **判定关键**：地理图形的数据必须**同时具备"空间精度"与"属性含义"**。只有坐标没有属性 = 定位图（导航，不是信息图形）；只有属性没有坐标 = 编目型。

### A.2 四问判定检验

1. **位置相关性检验**：位置本身是否携带解释力？（"为什么在这"是读者的问题之一？）
   → 是：地理图形。
   → 否（地点只是标签）：用 [编目型](03-编目型信息图形概念定义.md)，别画地图。
2. **几何层级检验**：数据是点、线、面还是场？
   → 决定后续全部图形选择，且**不可混用同一套色阶**（点用大小、面用填色，语义不同）。
3. **归一化检验**：面数据是否已除以面积/人口？
   → 未归一化的面着色 = **错误图形**（大省永远显眼，实为面积效应）。这是地理图形第一号技术错误。
4. **投影检验**：地图范围决定了投影选择。
   → 小范围（省/市）：可用等角投影，形状保真。
   → 全国：必须用国家规定的标准地图投影与版式（见 F 合规）。
   → 全球：慎用墨卡托（高纬面积夸大可达 4 倍以上）。

### A.3 与相邻门类的边界

| 易混对象 | 分界点 |
|---|---|
| **导航地图 / 底图** | 导航回答"怎么走"，地理图形回答"为什么分布如此"。前者是工具，后者是论点。 |
| **编年型** | 若"位置"只是事件的标签列，主轴仍是时间 → 编年型。二者叠合（行军图、迁徙史）= 混合型。 |
| **层级型** | 行政区划本身是层级（国→省→市），但一旦落到地图上并以面着色表达量，主逻辑已变为地理。纯区划树（不画地图）仍属层级型。 |
| **网络图** | 有地理坐标的网络 = 地理图形；抽象拓扑（地铁线路示意图、无坐标网络）= 网络图。**示意图是刻意的地理失真，属另一类。** |

### A.4 常见数据缺陷与处置

| 缺陷 | 处置 |
|---|---|
| 坐标系混用（WGS84 点叠在 GCJ-02 底图上） | 统一转换到与底图一致的坐标系；中国境内使用互联网地图须用 GCJ-02 |
| 面数据未归一化 | 除以面积或人口，并在图例标注"每万人/每平方公里" |
| 分级方法随意（等距分级导致一档吞掉 80% 区域） | 改用分位数（quantile）或自然断点（Jenks），并在注中声明 |
| 缺失区域未处理 | 用**专用灰色**（hatch 或 neutral gray）标注"无数据"，不可留白（留白会被读成"零"） |
| 点数据叠压严重 | 用聚合（hexbin / 网格汇总）或热力，不可无限堆叠标记 |
| 边界精度过高（1:100 万数据画全国小图） | 按输出尺寸简化几何，避免"锯齿线"与文件膨胀 |

## B 借用的统计图形与计算方式

### B.1 图形谱系

| 借用图形 | 几何 | 编码通道 | 适用 | 硬约束 |
|---|---|---|---|---|
| **分级设色图**（Choropleth） | 面 | 填色明度/色阶 | 比率型面数据 | **必须归一化** |
| **符号图**（Proportional Symbol） | 点 | 圆面积 | 绝对量（总量） | 面积而非直径；`r ∝ √v` |
| **点密度图**（Dot Density） | 点集 | 点的疏密 | 分布密度 | 一点 = 固定基数 |
| **等值线图**（Isarithmic） | 栅格 | 线距 + 填色 | 连续场 | 需插值算法，注意边界外推 |
| **流向图**（Flow Map） | 线/流 | 线宽 + 箭头 | OD 迁移 | 线宽 ∝ √流量，避免遮挡 |
| **变形图**（Cartogram） | 面（变形） | 面积 | 绝对量对比 | 牺牲地理真实性，须明示 |
| **热力图**（Heatmap） | 栅格 | 色阶 + 模糊半径 | 点密度 | 半径选择决定结论，须标注 |
| **六边形分箱**（Hexbin） | 网格 | 色阶 | 点密度 | 比行政区更中性，避免 MAUP |
| **棱柱图**（Prism Map） | 面 + 体 | 高度 | 绝对量 | 唯一合法的"体"用法 |
| **示意图**（Schematic） | 拓扑 | 位置（失真） | 结构关系 | 必须声明"非等比" |

### B.2 计算方式

地理图形的计算负担远高于其他门类，其中三项是决定成败的关键：

1. **投影变换**：`(lon, lat) → (x, y)`。选择即失真管理：
   - 墨卡托（Mercator）：保角不保积，高纬面积夸大（格陵兰 ≈ 非洲的视觉错觉）；
   - 等积（Equal-area，如 Albers、Mollweide）：保积不保形，适合分级设色；
   - 罗宾逊/温克尔（compromise）：折中，适合全球概览。
   **分级设色图必须用等积投影**，否则面积即欺骗。

2. **分级方法**（对同一数据，五种分级会产生五种不同结论）：
   - 等距（Equal Interval）：适合均匀分布，易被极值主导；
   - 分位数（Quantile）：每档数量相等，色彩均衡，但掩盖真实差距；
   - 自然断点（Jenks）：类内方差最小，视觉最"自然"，但算法不透明；
   - 标准差：突出偏离均值的极端；
   - 手动分级：适合有政策阈值的场景（如"人均 1 万美元"）。
   → **必须声明所用方法**；这是地图可信度的底线。

3. **密度归一**：`density = value / area`（或 `/ population`）。未归一化的"总量图"几乎总是误导。

4. **符号面积映射**：`r = r_min + (r_max − r_min) × √((v − v_min)/(v_max − v_min))`。

5. **流向线宽**：`width ∝ √flow`，并做**交叉避让**（曲率调整）以防线束糊成一团。

6. **插值**（等值线）：IDW / 克里金。插值半径越大，图越平滑也越"编造"，须标注方法。

7. **几何简化**（Douglas–Peucker）：按输出 DPI 设定容差，控制细节与文件体积。

### B.3 选择决策表

| 读者问题 | 选用 | 理由 |
|---|---|---|
| 哪个区域的比例更高？ | 分级设色（已归一化） | 面即区域 |
| 哪个城市的总量更大？ | 符号图 | 点承载绝对量 |
| 人口/事件在哪里密集？ | 点密度 / 热力 / hexbin | 连续密度 |
| 人和货如何流动？ | 流向图 | 线承载关系 |
| 各区域量的相对大小（不看地理） | 变形图 | 面积即数据 |
| 结构关系（线路、枢纽） | 示意图 | 可读性优先于真实 |

## C 视觉编码

### C.1 编码总表

| 视觉变量 | 在地理图形中承担什么 | 强度 |
|---|---|---|
| **面** | 区域填色、底图陆地/水域 | ★★★★★（主通道） |
| **位置** | 唯一的组织骨架（真实坐标） | ★★★★★（不可替代） |
| **线** | 边界、路径、流向、等值线 | ★★★★ |
| **点** | 城市点、事件点、符号锚点 | ★★★★ |
| **体** | 棱柱高度（唯一合法用法） | ★★ |
| **符号** | 图标、象形标记、比例符号 | ★★★ |
| **色彩** | 色阶（顺序/发散/分类） | ★★★★★（决定结论） |
| **文字** | 地名注记、图例、比例尺 | ★★★★（合规载体） |

### C.2 逐项要点

**面（填色）**
- **色阶类型必须与数据性质匹配**：
  - 顺序数据（量、比率）→ **单色相顺序色阶**（浅→深），3–7 档，档数 ≤ 7；
  - 有中点数据（增长率、盈亏）→ **发散色阶**（双色相 + 中性中点），中点必须设在语义零值；
  - 类别数据（土壤类型）→ **定性色阶**（≤ 8 色，明度接近、色相区分）。
- **绝对禁止**在顺序数据上用"彩虹色阶"（jet/rainbow）——它制造虚假边界、不可被色盲辨识、且明度不单调。
- 无数据区用**专用中性灰 + 斜纹**，并在图例单列一项。
- 陆地/水域基色对比要弱（明度差 5–10%），底图不得抢数据的视觉权重。

**位置（骨架）**
- 版面裁剪（crop）要保留**地理语境**：裁掉邻接区域会让读者误判"边缘即边界"。
- 必须标注**朝向**（指北针，仅在非正北向上时强制）与**比例尺**。
- 中国全图版式有强制规范，见 F.2。

**线**
- 边界线：国界 > 省界 > 市界，线宽递减（如 1.2 / 0.8 / 0.5px），**国界线必须为最重且最清晰的一级**。
- 流向线：线宽编码流量，箭头编码方向；**箭头不得密到连成实线**。
- 等值线：细线 + 数值标注（沿线上中断留白），主等值线（如 0 值线）加重。
- 路径线：用**曲线化**（贝塞尔）替代折线，减少视觉噪声；但对真实轨迹（如航海）必须保留原始折点。

**点／符号**
- 比例符号（圆）用面积编码，**必须给 2–3 个参考圆**（如"1 万 / 10 万 / 100 万"）作为图例，否则读者无法估量。
- 点标记要有**描边（白边 1.5–2px）**，保证叠压在深色底图上仍可辨识。
- 图标符号须统一视角（俯视或正视），不可混用。

**体**
- 唯一合法用法：**棱柱图**（区域底面 + 高度 = 数值）。高度必须对应真实比例，且需侧向光源产生轻微明暗以助读。
- 禁止：给平面地图加"厚度"作装饰（会让人误读为量）。

**色彩（合规重点）**
- 中国政区图着色不得使用**暗示政治实体**的配色（如用不同色系区分台湾、港澳与内地）。
- 单色方案（灰度/单色相）在印刷与无障碍场景下更稳健，优先考虑。

**文字（注记）**
- 注记排布规则：优先水平，其次沿要素走向；**避让**优先于完整（宁可省略，不可压盖）。
- 层级：国家名 > 省名 > 市名 > 地物名，字号依次递减（约 1.4 倍级差）。
- 地名用字必须为**标准地名**（以国家地名管理部门公布为准），不得使用非规范简称。
- 单位与口径写在图例或注中（"人/平方公里，2020 年"）。

### C.3 编码禁忌

- ❌ 面数据未归一化就着色（最常见、最严重的错误）
- ❌ 彩虹/jet 色阶
- ❌ 圆符号用直径编码数值（面积失真）
- ❌ 无数据区留白（被读成 0）
- ❌ 只给一个参考符号、不给系列参考值
- ❌ 全球图用墨卡托做面积比较
- ❌ 示意图未声明"非等比"
- ❌ 中国地图漏绘南海诸岛、台湾岛、海南岛等法定要素（详见 F）
- ❌ 使用境外未备案地图服务作为底图

## D 数据／信息架构

### D.1 层结构（自下而上五层）

```
┌─ 叙事层   主标题（空间判断）/ 导语 / 结论标注
├─ 注记层   地名、数值标注、引线
├─ 数据层   填色/符号/流线/等值线（承载论点）
├─ 底图层   陆地、水域、行政界线（弱化）
└─ 框架层   图例、比例尺、指北针、审图号、来源
```

**关键纪律**：底图层必须**显著弱于**数据层。检验方法——眯眼看图，若先看到国界再看数据，则底图过重。

### D.2 五种架构模式

| 模式 | 结构 | 适用 | 容量 |
|---|---|---|---|
| **单幅主图** | 一张地图 + 图例 | 单一论点 | 1 个变量 |
| **主图 + 局部放大** | 主图 + 2–3 个 inset | 全国 + 重点城市/岛屿 | 1–2 个变量 |
| **小倍数**（Small Multiples） | 同一投影的 n 张小图并置 | 时间对比、类别对比 | 3–9 帧 |
| **双变量图** | 色相 + 图案 / 色相 + 符号 | 两个维度的交叉 | 2 个变量 |
| **地图 + 图表联动** | 地图 + 侧栏条形/折线 | 空间 + 排序双读 | 2 个视图 |

> **inset 的必要性**：中国全图必须处理南海诸岛与台湾的呈现问题，标准做法是**主图 + 南海诸岛附图（右下角 inset）**，这是版式合规的组成部分，不是可选项。

### D.3 折叠策略

1. **尺度折叠**：全国 → 省 → 市，每级只显示该级可辨的要素；跨级混画必然糊。
2. **要素折叠**：底图只保留与论点相关的要素（讲人口分布时，不必画全部高速路网）。
3. **数值折叠**：用 5–7 档分级替代连续渐变，人对档位的比较快于对渐变的比较。
4. **图例折叠**：图例项 ≤ 7；超出则改用"两段式图例"（主色阶 + 单列例外项）。

### D.4 信息层级配额

- 变量数：**1（最佳）/ 2（上限）**
- 分级档数：**3–7**
- 图例项：**≤ 7**
- 注记数量：**大城市 ≤ 15、全省 ≤ 30**（超出则引发注记战争）
- 文字总量：**60–200 字**（地图本身信息量大，文字需极简）

## E 视觉叙事架构

### E.1 阅读路径

| 模式 | 路径 | 心理模型 |
|---|---|---|
| 全图概览 | 整体色块分布 → 焦点区 → 图例 | 先看"哪里不一样" |
| 主图+inset | 主图 → 附图 → 图例 | 先全境后细节 |
| 小倍数 | 第一帧 → 逐帧比较 → 末帧 | 找变化 |

地理图形的第一眼永远是**"分布形态"**（聚集、带状、离散、梯度），而非具体数值。因此标题应当直接说出形态判断，而不是描述变量。

### E.2 四种叙事模式

| 模式 | 结构 | 传达的判断 | 场景 |
|---|---|---|---|
| **分布式** | 单幅全境着色 | "不均匀，且有条带/集群" | 人口、产量、发病率 |
| **走廊式** | 沿线/沿河高亮 | "沿这条轴聚集" | 经济带、流域、交通廊道 |
| **中心—边缘式** | 核心区 + 渐弱外围 | "向心集中" | 都市圈、创新扩散 |
| **流动式** | 流线 + 起讫点 | "从这里流向那里" | 迁徙、物流、贸易 |

### E.3 叙事节奏

- **起**：整体分布形态（读者必须先建立"哪里多哪里少"的全局印象）。
- **转**：**一处反常区域**——用高亮描边（而非改色）圈出，配一句解释。全图仅一处。
- **合**：右下角落的**总结数字或判断**（"前 5 省占全国 46%"），常与 inset 共处一角。

> **地图的"焦点"不能靠颜色堆出来**。因为面已经被色阶占满，唯一可用的强调手段是**描边、引线、放大框、留白**这四种"非填色"通道。

### E.4 图文分工

| 通道 | 只负责 | 禁止 |
|---|---|---|
| 主标题 | 空间形态判断（"九成产量集中在三条河谷"） | "全国分布图" |
| 副标题 | 变量 + 单位 + 年份 + 分级方法 | 重复标题 |
| 图例 | 色阶/符号的量化对应 | 解释性长句 |
| 注记 | 地名 + 关键数值 | 因果论述 |
| 脚注 | 数据来源、投影、审图号 | 广告语 |

## F 合规与制图纪律（中国地图强制项）

地理图形是唯一有**法律强制约束**的信息图形门类。以下为不可协商的红线。

### F.1 底图与服务来源

- **只可使用**经批准的地图服务：腾讯地图、高德地图、百度地图、自然资源部"天地图"。
- **禁止**使用 Google Maps、Apple Maps、Bing（海外版）、OpenStreetMap 直连瓦片、Mapbox 等未在国内取得测绘资质的境外地图源作为底图。
- 不得在任何产出中内置、预置或泄露可用的地图 API Key；密钥应由后端代理持有，前端仅走代理。
- 中国境内互联网地图坐标须统一为 **GCJ-02**；测绘成果使用 **CGCS2000**。坐标系混用会导致位置偏移，属于质量事故。

### F.2 版式与要素（标准地图）

- 中国全图**必须**完整表示：台湾岛、海南岛、南海诸岛、钓鱼岛及其附属岛屿等法定要素，**不得漏绘、错绘**。
- 台湾、香港、澳门均为中国的一部分，图上不得以任何方式暗示其为独立政治实体（不得单独用异色、异形、断线、加注国名等方式区分）。
- 国界线绘制必须以**自然资源部发布的标准地图**为准，不得自行勾绘。
- 公开使用的地图应标注**审图号**（如"GS(20XX)XXXX号"）；未取得审图号的自制地图不得公开出版、展示或用于商业宣传。
- 标准地图下载与审图申报入口：自然资源部标准地图服务（bzdt.ch.mnr.gov.cn）。
- 涉及南海诸岛时，采用**主图 + 右下角南海诸岛附图**的标准版式，不得为版面美观而省略。

### F.3 内容与数据

- 不得标注军事禁区、涉密单位、未公开的敏感坐标。
- 批量点位数据须符合《个人信息保护法》：不得收集、存储或公开发布他人位置信息；个人轨迹类数据仅限本地私有存储。
- 统计数据须标注来源、年份、口径；行政区划名称与代码以国家最新公布为准。

### F.4 自检顺序

1. 底图来源是否在白名单内？
2. 坐标系是否与底图一致？
3. 中国全图是否包含全部法定要素、是否有南海诸岛附图？
4. 台湾、港澳的表示是否与内地一致？
5. 国界线是否来自标准地图？
6. 是否标注审图号（如为公开发布）？
7. 面数据是否已归一化？分级方法是否声明？
8. 色阶类型是否与数据性质匹配？是否避免了彩虹色阶？
