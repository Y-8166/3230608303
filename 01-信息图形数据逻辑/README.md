# 01 信息图形数据逻辑 · 板块入口

> **一句话**：这一层只回答「这份数据为什么必须这样组织」，不回答「它长什么样」。
> **纪律**：本层**不含任何图片**，只用文本链接指向 `02-` 的案例；五份门类定义一律 A–E 五段，末尾附 F 节自检清单。
> **上级**：[仓库首页](../README.md) ｜ **下游**：[02 类型案例](../02-信息图形类型案例/README.md)

|---|---|---|---|

## 怎么用

1. 拿到数据，先用每份文档 **A.2 四问判定检验** 落到五大门类之一；
2. 遇到边界，查 **A.3 与相邻门类的边界**（编目／字母表、编目／层级、地理／编年三组）；
3. 定完逻辑再去 [02 类型总览](../02-信息图形类型案例/00-类型总览.md) 选形态——**先定逻辑、再选形式**，反过来会造出并不存在的先后关系。

## 体例约定

- 固定五段：A 基本数据逻辑 / B 统计图形与计算 / C 视觉编码 / D 数据信息架构 / E 视觉叙事架构，顺序不得调整。
- 每份 C 节须有「编码禁忌」❌ 列表；末尾 F 节为二元判断的自检清单。
- 所有判据必须可执行：给数值、给阈值、给二元检验。
- 每份文档须有指向 `02-` 的案例入口（集中在 G 节），但**永不嵌图**——这样理论文档在 GitHub 裸页、终端、Word 导入等纯文本环境里都能完整阅读。

## 合规提示

地理图形是唯一受法律强制约束的门类，制图前必读 [05 文档 F 节](05-地理图形信息图形概念定义.md)：底图须用腾讯／高德／百度／天地图，中国全图必须完整表示台湾岛、海南岛、南海诸岛等法定要素并附南海诸岛附图，国界线以自然资源部标准地图为准。
