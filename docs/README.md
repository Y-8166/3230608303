## 为什么单独放一个目录

早期这两份文件与 `01-`…`06-` 并列在根目录，看起来像「第 7、第 8 个板块」，实际它们既不是逻辑层也不是案例层。把它们收进 `docs/`，根目录就只剩：`README.md`（总索引）+ 六个编号板块 + `scripts/`（工具）。

## 校验

`scripts/validate_repo.py` 会检查：根目录只允许 `README.md` 一份 Markdown；治理文档必须在 `docs/` 内。新增治理类文档请放本目录，不要放回根目录。
